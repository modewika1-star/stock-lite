# 📦 My Inventory System

A small inventory-management interface exercise with controls for adding, viewing, editing, and deleting products.

## ✨ Interface overview

The page includes:

- **Add Product** action.
- **Show All Products** action.
- **Edit Product** action.
- **Delete Product** action.
- A dedicated area for displaying inventory information.

## 🎨 Styling

- Light neutral page background.
- High-contrast heading and buttons.
- Blue action buttons with hover feedback.
- A bordered product-list panel.

## 🛠️ Built with

- HTML5
- CSS3
- JavaScript (intended interaction layer)

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t11.git
cd t11
~~~

Open `index.html` in a browser.

## 📁 Main files

- `index.html`: inventory heading, action buttons, and product-list container.
- `js/script.js`: referenced by the page for inventory interactions.

> The current HTML references `js/script.js`. Make sure that file exists in the checked-out project for the inventory buttons to perform their actions.
